# История изменений проекта «Архитектор Истории»

## [1.7.0] — 2026-11-07
**Git commit**: `5028d48` | **Git tag**: `v1.7.0`
### Улучшено и оптимизировано
- **Оптимизация верхнего отступа на смартфонах (Dynamic Island / Notch)**:
  - Уменьшен избыточный верхний зазор на мобильных устройствах с Dynamic Island (iPhone 14 Pro/15/16) и чёлками.
  - Переменная `--safe-top` скорректирована с учётом высоты системного статус-бара: `max(calc(env(safe-area-inset-top, 0px) - 8px), 10px)`.
  - Уменьшен внутренний отступ верхней строки шапки `.ghead-row-top` (`padding: 2px 14px 0`) и вертикальный зазор `.ghead` (`gap: 4px; padding-bottom: 5px`).
  - Скорректированы верхние отступы для экранов последствий (`.echohead`), пролога (`.prologuescr`), титульного экрана (`.titlescr`) и панелей кодекса (`.phead`).
- **Упрощение аудиосистемы (Единый тумблер звука)**:
  - Удалено тяжеловесное модальное окно поканальной настройки звука и ползунки.
  - Полностью удалён фоновый монотонный низкочастотный эмбиент (`ambient drone`), исключены паразитные фоновые осцилляторы.
  - Сохранены чистые процедурные средневековые аудиоэффекты (Web Audio API без внешних файлов): звон монастырских колоколов при смене глав, шелест пергамента при навигации и скрип гусиного пера при выборах.
  - Управление звуком сведено к единому тумблеру вкл/выкл во всех трёх точках входа:
    1. Иконка колокола в шапке HUD (`#sndToggle`) мгновенно включает/выключает все звуки.
    2. Кнопка на титульном экране (`#titleSoundBtn`) переключает звук одним кликом.
    3. Карточка в листе персонажа (`#p-char`) переключает звук одной кнопкой.
  - По умолчанию при старте новой игры и первом входе звук остаётся выключен (`Muted`).
- **Синхронизация сборочных файлов**:
  - `index.html` и `_preview/index.html` синхронизированы байт-в-байт.

## [1.6.0] — 2026-11-05
**Git commit**: `0563b52` | **Git tag**: `v1.6.0`
### Добавлено
- **Гранулярная настройка звуков («Звуки обители»)**:
  - Реализован выбор 4 независимых каналов звучания:
    - 🔔 **Колокола Сен-Дени** (`bells`) — звон при начале пути, смене глав и ключевых вехах.
    - 📜 **Шорох пергамента** (`parchment`) — шелест манускриптов при открытии летописи, кодекса, карт и досье.
    - 🪶 **Перо писца** (`quill`) — скрип гусиного пера при принятии решений братом Лукой.
    - 🕯️ **Своды собора (Эмбиент)** (`ambient`) — тихий медитативный резонанс древних каменных стен.
  - Полнофункциональное модальное окно настройки звуков `#soundSettingsDlg`:
    - Главный переключатель мастер-звука с пояснением текущего статуса.
    - Средневековые тумблеры (`.med-switch`) для каждого канала.
    - Кнопки предварительного прослушивания `[▶ ТЕСТ]` (воспроизводят звук даже при отключенном мастер-звуке для удобства настройки).
    - Кнопки быстрых действий «Включить все» и «Выключить все».
- **Звук выключен по умолчанию (`Mute`)**:
  - При первом открытии игры звук отключен по умолчанию.
  - При нажатии «Начать новую игру» (в том числе из меню сброса или через пролог) звук принудительно переводится в выключенное состояние.
- **Точки входа в управление звуком**:
  - Экран запуска (`#scr-title`): кнопка с текущим статусом `🔔 Звук: Выключен (Настроить)`.
  - Шапка игры (HUD): объединённый блок кнопки быстрого выключения/включения звука (`#sndToggle`) и кнопки вызова настроек (`#sndSettingsBtn`).
  - Лист персонажа (`#p-char`): карточка «Акустика и звуки обители» со статусом и кнопкой быстрой настройки.
- **Горячие клавиши**:
  - `M` / `ь` — мгновенное включение / отключение звука.
  - `Shift+M` / `О` — открытие окна детальной настройки звука.
  - `Esc` — закрытие окна настроек.
