## 2. Сценарии отката (Шпаргалка команд Git)

### Сценарий А. Временный осмотр любого прошлого состояния (Безопасно, без потерь)
Если вы хотите просто запустить игру и посмотреть, как она работала на любом прошлом этапе, не затрагивая текущую ветку `main`:

```bash
# Переключиться на любую версию (например, v1.5.0 до внедрения настроек звука):
git checkout v1.5.0

# Или на версию v1.4.0 (до добавления портретов персонажей):
git checkout v1.4.0

# Чтобы вернуться обратно к самой свежей актуальной версии v1.6.0:
git checkout main
```

---

### Сценарий Б. Создать новую рабочую ветку из старой версии
Если вы хотите продолжить разработку на базе старой версии, оставив `main` нетронутой:

```bash
# Создать ветку 'branch-from-v1.5' на основе состояния v1.5.0:
git checkout -b branch-from-v1.5 v1.5.0
```

---

### Сценарий В. Полный и окончательный откат ветки main к прошлому состоянию
> **Внимание:** Перед жестким откатом ветки `main` убедитесь, что текущее состояние сохранено в резервной ветке (она уже создана и отправлена в GitHub как `backup/checkpoint-v1.6.0`).

```bash
# 1. Создать локальную резервную ветку на всякий случай:
git branch backup-before-rollback

# 2. Жёстко откатить ветку main до нужного тега:
# Пример 1: Откатить только настройки звука (вернуться к v1.5.0):
git reset --hard v1.5.0

# Пример 2: Откатить и звук, и портреты персонажей (вернуться к v1.4.0):
git reset --hard v1.4.0

# Пример 3: Откатить до исходного HUD (вернуться к v1.2.6):
git reset --hard v1.2.6

# 3. Синхронизировать удалённый репозиторий GitHub (если требуется принудительно обновить remote):
git push origin main --force
```

---

### Сценарий Г. Отмена только одного конкретного коммита (Revert)
Если вы хотите аккуратно отменить только одно конкретное изменение, сохранив всю остальную историю:

```bash
# Отменить только коммит настроек звука (0563b52):
git revert 0563b52

# Отменить только коммит добавления портретов персонажей (af57a39):
git revert af57a39
```
Git создаст новый коммит, который зеркально удалит указанные изменения.

---

### Сценарий Д. Как вернуть всё назад, если передумали откатываться
Так как мы создали ветку `backup/checkpoint-v1.6.0` и тег `v1.6.0`:

```bash
git checkout main
git reset --hard v1.6.0
git push origin main --force
```
Всё мгновенно возвращается к состоянию на 07.11.2026.

Перед любыми действиями рекомендуется проверять идентичность основной и превью-версии:
```bash
diff -u index.html _preview/index.html
```

Если вывод пустой — файлы синхронизированы на 100%.
