# Stitch Prompt: AI-first необанк

## Контекст продукта
Мобильный финтех-кошелёк с персональным AI-ассистентом, объединяющий банковские услуги (IBAN, карта, переводы) и криптовалюту (покупка/продажа/хранение 2–3 активов) в едином интерфейсе. Главный экран — утренний чек-ин «Сколько могу потратить сегодня», все финансовые решения принимаются через диалог с AI. ЦА: 20–40 лет, пользователи необанков со средним опытом крипты и финансовой грамотностью.

## Визуальный язык
Тон бренда — дружелюбный и экспертный: спокойная уверенность, никакого финансового жаргона, интерфейс помогает принимать решения, не перегружая. Визуально — минимализм с выразительными AI-взаимодействиями: чистый функциональный базовый слой + живые микровзаимодействия, динамическая визуализация рекомендаций, контекстные анимации. Цветовая схема: спокойные нейтральные базовые тона (белый/светло-серый/тёмно-графит для тёмной темы) + один акцентный цвет для AI-элементов и проактивных инсайтов (например, глубокий тиール или электрик-блу). Сетка 8px, скругления 12–16px, мягкие тени для глубины.

## Экраны для генерации
Сгенерируй 5 связанных экранов в едином стиле. Каждый экран — отдельный артборд.

### Экран 1: Онбординг / KYC / Welcome
- Назначение: Регистрация, верификация личности, выдача IBAN, привязка виртуальной карты, первый вход в продукт.
- Контент: Прогресс-бар шагов (1. Данные / 2. Документы / 3. IBAN и карта / 4. Готово); пошаговые экраны с крупным заголовком, коротким пояснением, действием (кнопка «Продолжить» / загрузка фото / ввод кода); итоговый экран «Твой счёт готов» с показанным IBAN и виртуальной картой, CTA «Открыть приложение».
- **Слоты под визуал**:
  - Hero_Placeholder_Onboarding — иллюстрация на каждом шаге (abstractions: безопасность, скорость, простота)
  - Icon_Slot_Step_1 — иконка профиля/данных
  - Icon_Slot_Step_2 — иконка документа/щита
  - Icon_Slot_Step_3 — иконка IBAN/карты
  - Pattern_Background_Onboarding — лёгкий фоновый паттерн (grid/dots) для глубины
  - Logo_Placeholder_Header — область под логотип в шапке

### Экран 2: Главный экран — «Сколько могу потратить сегодня»
- Назначение: Утренний чек-ин — пользователь видит одно число (safe spend) с цветовым статусом, может задать уточняющий вопрос AI.
- Контент: Верх — приветствие + дата. Центр — крупное число «₽42 300» с цветовым чипом статуса (Safe/Comfortable/Watch Out/Overspent) и одной фразой-инсайтом («После аренды и целей остаётся ~₽1 400/день»). Тап по числу/чипу → раскрывается чат с AI (переход на Экран 3). Нижняя навигация: Главный / Чат / Карта / Профиль. Плавающий action-кнопка «Что если?» открывает модалку с полем ввода для what-if сценария.
- **Слоты под визуал**:
  - Hero_Placeholder_Home — анимированный «живой Blob» (как у Olbey) или цветовая волна, отражающая статус дневного лимита
  - Icon_Slot_Status_Chip — иконка внутри цветового чипа (check / alert / warning)
  - Pattern_Background_Home — тонкий градиентный паттерн на фоне числа
  - Logo_Placeholder_Header — логотип в шапке
  - Icon_Slot_FAB — иконка плюса/искры для FAB «Что если?»

### Экран 3: AI-чат — основной интерфейс
- Назначение: Диалог на естественном языке — баланс, траты, цели, правила, крипта, карта, безопасность. Ответы — карточки с данными, графиками, кнопками подтверждения.
- Контент: Шапка с названием «AI-ассистент» и статусом «Онлайн». История сообщений: пользователь спрашивает («Сколько могу потратить на куртку?»), AI отвечает карточкой — заголовок, разбивка чисел, кнопка «Ок» / «Подробнее». Внизу — поле ввода с микрофоном (голос) и кнопкой отправки. Быстрые чипы-подсказки над полем: «Баланс», «Траты за неделю», «Создать цель», «Купить USDC».
- **Слоты под визуал**:
  - Hero_Placeholder_Chat_Empty — иллюстрация для пустого состояния чата (первый вход)
  - Icon_Slot_AI_Avatar — аватар AI-ассистента (анимационный пульсирующий дот)
  - Icon_Slot_User_Avatar — плейсхолдер под аватар пользователя
  - Icon_Slot_Quick_Chips — иконки для быстрых чипов (кошелёк, график, цель, крипта)
  - Pattern_Background_Chat — едва заметный паттерн в фоне сообщений
  - Logo_Placeholder_Header — логотип в шапке

### Экран 4: Крипто-модуль — обмен и покупка
- Назначение: Мгновенный обмен фиат ⇄ крипта, покупка/продажа 2–3 активов (USDC, BTC, ETH), единый баланс.
- Контент: Верх — табы «Обмен» / «Портфель». Вкладка «Обмен»: два поля с валютами (FROM / TO), курс в реальном времени, калькулятор «Получите ~X», большая кнопка «Обменять». Вкладка «Портфель»: карточки активов (иконка, название, баланс в фиате, % за 24ч), тап → детальный экран с графиком и кнопками «Купить / Продать / Перевести». Единый баланс в шапке: «Всего: ₽1 240 000 (фиат ₽890 000 + крипта ₽350 000)».
- **Слоты под визуал**:
  - Hero_Placeholder_Crypto — илюстрация/анимация для пустого портфеля или фон таба «Обмен»
  - Icon_Slot_Assets — иконки 3 активов (USDC, BTC, ETH) — отдельными слоями
  - Icon_Slot_Swap_Arrow — анимированная стрелка обмена между полями
  - Pattern_Background_Crypto — лёгкий паттерн для глубины карточек активов
  - Logo_Placeholder_Header — логотип в шапке

### Экран 5: Цели накоплений + авто-правило
- Назначение: Создание цели («Отложить 100к к Новому году»), AI предлагает правило авто-перевода, пользователь подтверждает тапом.
- Контент: Список целей (активные / достигнутые). Карточка цели: название, дедлайн, прогресс-бар (круглый/линейный), накоплено / осталось, дневная/недельная сумма авто-перевода. Кнопка «Создать цель» → модалка: название, сумма, дата → AI показывает расчёт «Рекомендую откладывать ₽15 000 после каждой зарплаты (15%)» → чекбокс «Автоматически переводить» + кнопка «Подтвердить». Пустое состояние: иллюстрация + «Твои цели появятся здесь».
- **Слоты под визуал**:
  - Hero_Placeholder_Goals_Empty — иллюстрация для пустого состояния (мечты/планы)
  - Icon_Slot_Goal_Categories — иконки категорий целей (путешествие, авто, образование, подушка)
  - Icon_Slot_Progress_Ring — декоративный прогресс-кольцо (background layer)
  - Pattern_Background_Goals — фоновый паттерн для карточек целей
  - Logo_Placeholder_Header — логотип в шапке

## Технические требования
- Чистые редактируемые слои при экспорте в Figma.
- Сетка 8 px.
- Единая типографика на всех экранах (Display / Headline / Body / Caption, веса Regular / Medium / Semibold).
- Все placeholder-зоны под визуал — отдельными слоями с понятными именами (Hero_Placeholder_Onboarding, Icon_Slot_Assets, Pattern_Background_Home и т.д.).
- Поддержка Light / Dark темы — цветовые токены вынесены в стили.
- Компоненты: Button (Primary/Secondary/Ghost), Input, Chip, Card, BottomNav, TopBar, ProgressRing, Avatar — как отдельные компоненты в Figma.
